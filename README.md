# posteto-tmp

Almacén de paso de [posteto](https://github.com/wePickaxe/Posteto), que es privado.

Instagram no acepta archivos, solo enlaces. Para publicar una pieza, posteto la deja aquí como adjunto de la versión «tmp», Instagram la descarga y posteto la borra en cuanto acaba, normalmente en pocos minutos. Si algo se corta, la siguiente vuelta borra lo que lleve más de 2 horas.

Aquí solo pasan piezas que se van a publicar. No hay nada más en este repositorio.
